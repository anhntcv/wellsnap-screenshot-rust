### Русский

- Скриншот всего экрана: редактор открывается с уже выделенным экраном под указателем. Windows: Ctrl+PrtSc, macOS: ⌘⇧1.
- Сохранение всего экрана в файл без редактора. Windows: Shift+PrtSc, на macOS включается в настройках (⌥⇧⌘1).
- Если вы обновились, новые клавиши выключены, чтобы не отнять их у других программ: Настройки > Горячие клавиши > «Включить». Оба действия есть и в меню значка WellSnap.
- Исправлено: на macOS окно настроек иногда открывалось только со второго нажатия.

### English

- Full screen screenshot: the editor opens with the screen under the pointer already selected. Windows: Ctrl+PrtSc, macOS: ⌘⇧1.
- Save the full screen to a file without the editor. Windows: Shift+PrtSc; on macOS turn it on in Settings (⌥⇧⌘1).
- After an update the new keys are off, so they are not taken from other apps: Settings > Shortcuts > "Turn on". Both actions are also in the WellSnap icon menu.
- Fixed: on macOS the Settings window sometimes opened only on the second click.
